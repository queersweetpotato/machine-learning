Packages needed

for the dataset, you need to install ucimlrepo by running "pip install ucimlrepo" or "pip3 install ucimlrepo"

for running the notebooks, you also need to install numpy (version 2.5.3), pandas (version 3.0.6), matplotlib (version 3.11.2), and scikit-learn (version 1.9.1).

The final report has already been compiled into a pdf, but if you want to compile it yourself you will need to install latex.
